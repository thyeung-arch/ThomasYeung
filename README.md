# 屋企洗費表｜居家帳簿

一個單一 HTML 檔案嘅屋企每月洗費記錄網站，唔使裝任何嘢，用瀏覽器打開就用得。

## 檔案

- `家居支出表.html` — 網站本體（HTML + CSS + JavaScript，內嵌 Chart.js）

## 主要功能

- **月份揀選**：頭部可以揀返 1 月至 12 月，預設跟返而家個月份
- **洗費明細表**：內建 12 個常見類別（租金／供樓、水電煤、餐飲費、交通費、醫療費、服裝費、旅行費、教育費、保險費、日用品雜貨、電話上網費、娛樂消閒），每一行可以：
  - 改類別名稱
  - 加備註
  - 輸入金額（£）
  - 刪走呢一行
  - 用「＋ 加多個洗費項目」加新類別
- **預算追蹤**：可以 set 呢個月嘅預算，自動顯示已洗百分比、剩返幾多或者使爆咗幾多
- **總計**：表格最底自動加總所有金額
- **兩個圖表**：
  - 長條圖 — 各類別金額由多到少排列
  - 圓形圖（甜甜圈圖）— 各類別佔成個月洗費嘅百分比
- 全站香港口語書面語，貨幣單位英鎊（£）

## 點樣用

1. 直接用瀏覽器打開 `家居支出表.html`（雙擊個檔案，或者拖入瀏覽器）
2. 揀返而家嘅月份
3. 響表格入面填低金額同備註
4. 有需要嘅話加新類別、set 預算
5. 圖表同總計會即時自動更新

## 注意事項

- **資料唔會自動儲存**：呢個係純前端網頁，冇連任何資料庫或伺服器。重新整理個頁面、或者關咗個分頁再打開，入咗嘅資料就會冇晒
- 想保留資料嘅話，記得自己截圖，或者將金額抄落其他地方（例如 Excel）
- 網頁需要連接網絡先可以載入字體（Google Fonts）同圖表庫（Chart.js CDN），如果離線用會少咗啲樣式同睇唔到圖表

## 技術

- 純 HTML / CSS / JavaScript，冇用任何 framework
- 圖表用 [Chart.js](https://www.chartjs.org/)（透過 cdnjs 載入）
- 字體用 Google Fonts 嘅 Noto Serif TC / Noto Sans TC

## 之後可以加嘅功能（如果需要，可以再問）

- 加「日期」欄，記低每一筆洗費嘅實際日期
- 加「年份」揀選，唔淨係月份
- 儲存資料（例如匯出做 CSV / Excel，或者用瀏覽器本機儲存）
- 跨月份比較（例如比較 6 月同 7 月嘅洗費）
